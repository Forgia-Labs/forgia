# Getting Started

Forgia has three components: a Go CLI binary, a vault (`.forgia/`) in each project, and Claude Code slash commands for the spec workflow.

## Prerequisites

- [mise](https://mise.jdx.dev/) — task runner and tool manager
- [Claude Code](https://claude.ai/claude-code) — for slash commands (`/fd-new`, `/fd-review`, etc.)
- [Docker](https://docs.docker.com/get-docker/) — optional, only for OpenHands autonomous agents
- [GitHub CLI](https://cli.github.com/) — optional, only to create FDs from GitHub issues
