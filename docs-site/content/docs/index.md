# Forgia

Forgia is a spec-driven development framework that transforms Feature Designs into agent-executable specs.

```
FD (Feature Design)  →  SDD (Spec-Driven Dev)  →  Code
humans decide            agents execute             output
```

## How it works

1. **Create a Feature Design** — describe what to build and why, with architecture and trade-offs
2. **Review the FD** — a gate ensures problem clarity, diagrams, and interfaces are defined
3. **Generate SDDs** — one execution spec per component, ready for agents
4. **Assign and execute** — OpenHands, Claude Code, or manual implementation
5. **Verify and close** — confirm work logs are filled, acceptance criteria met
